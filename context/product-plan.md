# Product Plan

Last updated: 2026-07-08

## 1. V1 cooperativo local

### 1.1 Dos jugadores en una PC

El alcance actual es local en una sola PC. Ya existe una V1 con dos entidades de jugadores controladas con distintas teclas.

### 1.2 Camara compartida

Ambos jugadores comparten camara/pantalla.

### 1.3 Input

Teclado compartido es el input actual. Soporte de controles/gamepads es un objetivo cercano por comodidad.

## 2. Combate base

### 2.1 Armas actuales

La primera iteracion tiene espada, escudo y rifle como ataques basicos suficientes para empezar a evaluar calidad.

### 2.2 Refinamiento

Antes de agregar mas armas o ataques, refinar que espada, escudo y rifle se sientan bien tanto en visual como en gameplay.

### 2.3 Sistema basado en armas

El moveset cambia segun el arma equipada. Los jugadores no estan limitados a un rol fijo.

## 3. Loop de salas

### 3.1 Arenas/salas de dungeon

El formato principal es entrar a una sala, vencer enemigos y pasar a la siguiente.

### 3.2 Progresion

No definido. Puede ser skill tree, roguelike, mejoras de armas, una mezcla u otra opcion.

## A futuro

- Soporte de control/gamepad.
- Progresion ligera.
- Combos cooperativos.
